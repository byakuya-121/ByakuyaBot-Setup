# 白夜Bot (ByakuyaBot)

.NET 10 (WPF) で構築された「白夜Bot」のソースコードおよび自動パッケージング（インストーラー作成）環境です。
Deno および Engine スクリプトを自動同梱し、開発からインストーラー生成までをワンストップで行えるよう構成されています。

---

## 📦 主な特徴

- **.NET 10 (WPF) 対応**: 最新の .NET 10 環境で動作する Windows デスクトップアプリケーション。
- **依存環境の自動同梱**: 実行に必要な `deno.exe` や `Engine` フォルダ（各種スクリプト）を全自動でパッケージ内に配置。
- **自動ビルド＆パッケージ化**: PowerShell スクリプト 1 つで `dotnet publish` から Inno Setup によるインストーラー作成までをワンコマンドで完了。

---

## 🚀 インストール方法（ユーザー向け）

1. 本リポジトリ右側の **[Releases]** ページへアクセスします。
2. 最新バージョンの **Assets** から `ByakuyaBot_Setup_X.X.exe` をダウンロードします。
3. ダウンロードした `.exe` ファイルを実行し、画面の指示に従ってインストールしてください。

---
